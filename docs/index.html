What it does

A complete APK workshop that fits in your pocket.

Every stage of building an Android app, rebuilt as small, readable bash and Python. Nothing hidden, nothing downloaded behind your back.

Raw Java → APK

Point APKB at any Android source tree, whatever its folder layout. The scanner finds the manifest, resources, Java sources and libraries, then the pipeline compiles a release or debug APK.

HTML → APK wizard

Turn a website or local HTML project into a real WebView app. Splash screen, icon, theme colors, orientation, JS bridge, offline page and permissions, all from one guided wizard.

Broadcast Into Browser

Prefer a GUI? bash apkb.sh broadcast opens a graphical lab in your browser. Termux still does all the work; the page streams live progress, steps and the full console.

Try Before Build

Run your app in a phone frame before compiling. Your real layouts, drawables and Java code, interpreted live in the browser with touch, dialogs, toasts and multi-activity navigation.

Project Checker

Catches broken resource references, missing permissions and bad imports before any build starts, with the exact file and line, plus a hint for the fix and a built-in editor.

APK Inspector & Lab Doctor

Inspect any APK's manifest, permissions and contents. Lab Doctor diagnoses your toolchain, and every failed build saves a full log you can download from the page.

Broadcast Into Browser

A graphical lab, streamed from your terminal.

One command starts a local server and opens a polished web UI. Your device does every piece of processing; the browser is just the window.

  • Nine lab tools: Build APK, HTML → APK, Try Before Build, Analyze, APK Inspector, New Project, Lab Doctor, History & Logs, Settings.
  • Live everything: progress bars, build steps and the full console stream to the page in real time.
  • Download from the page: the finished APK lands in your browser. Every failed build downloads its log automatically.
  • Private by default: listens on 127.0.0.1 behind a one-time token. Pass --lan to reach it from other devices on your Wi-Fi.

Try Before Build

Run the app before it exists.

A phone simulator inside the lab interprets your actual project: layouts, drawables, values, assets and Java code, rendered in a touchable phone frame.

  • Real behavior: touch, dialogs, toasts, multi-activity navigation, lifecycle, rotation and dark mode.
  • Real subsystems: WebView with assets and JS bridge, custom Canvas views, SharedPreferences, Handler, Thread and AsyncTask.
  • Real permissions: camera, mic, location and notification requests use the browser's own prompt.
  • Fix in place: problems appear with the exact file:line, with a built-in editor to patch and reload instantly.
Honest limits: native .so code, OpenGL ES, Kotlin and third-party libraries can't run in a browser. Their classes are stubbed and listed under "Not supported in the preview".
Project Checker

Broken builds die before they start.

The checker scans sources, resources and the manifest together, and reports problems the way a compiler should: severity, exact location, and what to do about it.

  • Missing permissions inferred from the APIs you call.
  • Dangling @string/, @layout/ and R. references.
  • Duplicate jars, unsupported imports and manifest issues.

Get started

From zero to APK in one command.

APKB runs on Termux (Android) or any Linux with bash, Java and Python 3. Missing Android tools are installed for you on first run.

You sign it: APKB produces an unsigned APK by design. Sign it with apksigner and your own key before installing or publishing.
install
# grab APKB v2.0
$ git clone https://github.com/imademodsgg-hub/APKB.git
$ cd APKB

# terminal menu
$ bash apkb.sh

# or open the graphical lab
$ bash apkb.sh broadcast # add --lan for Wi-Fi devices
